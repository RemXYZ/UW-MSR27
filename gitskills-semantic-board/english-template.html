Skill review

A sample of skill files, summarized in English. Review the goal, task, and domain for each skill. Domains use a fixed list of labels, with more detailed categories for IT.

Reviews are stored in this browser. Export a JSON copy to keep or share them; you can import it later.

The expandable source is the original sampled text and may be in another language. GitHub links point to the current version, which may differ from the sample.
