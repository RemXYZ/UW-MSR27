# Combined review of 1,000 skills

Open `review-1000.html` for the combined sample, source texts and preliminary domains; `analyses-1000.json` and `domain-statistics-1000.md` contain the combined data and counts. The second set's rationales are translated from Polish into English, with the original text retained in the `justification_pl` field; goal and task summaries were not produced for those skills. Labels and summaries are AI-generated preliminary analyses, primarily of opening excerpts, not human-validated ground truth. The combined sample was selected in different stages and is not a random sample of the complete database.

The combined review attempts to load existing first-500 browser reviews when the browser exposes the same local storage. Export a backup from the original review first; the combined page can import either an old 500-skill export or a 1,000-skill export and merges reviews by SHA, replacing matching entries. Local-file storage behavior varies by browser. The older files and second-sample sources remain available and are not overwritten.

Regenerate the board with `python gitskills-semantic-board/build-1000.py`. It reads `analyses-1000.json` and the GitSkills sample database at `gitskills-sample-main/agent_skills_sample/agent_skills_sample.db` in the repository root; the database is not included in this repository. It overwrites the combined HTML and statistics. The first 500 were selected in stages; the next 500 were selected by ascending content SHA from nonempty representatives, excluding the first set. The related 3D embedding plots are in `../gitskills-pca-1000/`.
